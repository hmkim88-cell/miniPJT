## 1. 한 줄 요약
외국계 IT 기업 이직 준비자가 **레주메를 올리고 링크드인 공고(엑셀·PDF·ZIP·알림 메일)를 넣으면**, AI가 레주메를 요약하고, 공고를 **직종·직급·예상 연봉**으로 나눠 **나와 맞는 회사·공고 순위**와 **인터뷰 핵심 키워드**를 한 화면(📊 채용 대시보드)에서 보여주는 웹 서비스.

## 4. 안전 · 개인정보 지킨 것
- 서비스 서버는 **링크드인에 접속하지 않음** (스크래핑·로그인 대리 없음). 링크드인 자료는 사용자가 직접 받은 파일만 사용.
- 비밀번호·AWS 키는 받지도 저장하지도 않음. 키는 `.env`에만 두고 GitHub에 올리지 않음.
- GitHub에서 제외: 실제 DB(`*.db`), 암호화 키(`data/.resume.key`), `.env`, `data/ats_sources.json`.
- 레주메는 **동의한 경우만 암호화 보관**. 구인자에게는 요약만, 생년월일·사주·인연 점수는 보내지 않음.
- 나이로 판단하지 않음. 예상 연봉 기준표는 **가정치**임을 화면에 표시.
